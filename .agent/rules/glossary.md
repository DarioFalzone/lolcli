# Glossary — riot_lol_cli

## Términos de League of Legends

| Término | Significado |
|---------|------------|
| **ADC** | Attack Damage Carry — rol de tirador en la línea bot |
| **Bot** | Línea inferior del mapa (bot lane) |
| **Champion** | Personaje jugable |
| **CS** | Creep Score — minions eliminados |
| **Draft** | Fase de selección de campeones antes de la partida |
| **KDA** | Kills/Deaths/Assists ratio |
| **Meta** | Most Effective Tactics Available — las estrategias dominantes |
| **Pick rate (PR)** | Porcentaje de partidas donde se elige un campeón |
| **Skin** | Variante visual de un campeón |
| **Splash art** | Ilustración oficial de un campeón/skin |
| **Summoner** | Jugador / cuenta de LoL |
| **Win rate (WR)** | Porcentaje de victorias de un campeón |
| **Ban rate** | Porcentaje de partidas donde se banea un campeón |
| **Tier list** | Ranking de campeones por efectividad (S/A/B/C/D) |
| **Matchup** | Enfrentamiento entre dos campeones específicos |
| **Runes** | Sistema de personalización pre-partida |
| **Items** | Objetos que se compran durante la partida |

## Términos Técnicos del Proyecto

| Término | Significado |
|---------|------------|
| **Data Dragon (DDragon)** | CDN estática de Riot con datos y assets de LoL |
| **Summoner-V4** | API de Riot para datos de invocadores |
| **Match-V5** | API de Riot para datos de partidas |
| **Account-V1** | API de Riot para resolver Riot IDs |
| **PUUID** | Player Universally Unique Identifier |
| **Platform** | Servidor regional (la2, na1, euw1...) |
| **Regional route** | Ruta de API regional (americas, europe, asia) |
| **Anomaly** | Cambio estadístico significativo detectado por el meta analyzer |
| **Golden drafts** | Drafts de referencia para evaluar el scoring del draft advisor |
| **KB (Knowledge Base)** | Base de conocimiento del draft advisor con reglas y matchups |
| **Hextech** | Estilo visual de la interfaz de LoL (usado en nuestros templates) |

## Siglas del Proyecto

| Sigla | Significado |
|-------|------------|
| **CLI** | Command Line Interface |
| **ORM** | Object-Relational Mapping (SQLAlchemy) |
| **SPA** | Single Page Application (draft advisor frontend) |
| **CDN** | Content Delivery Network (Data Dragon) |
| **BD** | Base de Datos |
