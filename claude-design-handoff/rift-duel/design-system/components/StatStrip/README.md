# StatStrip

Fila de métricas del source: etiqueta en mayúsculas y valor grande con números tabulares.

- Para 3 a 5 datos de resumen: partidas, duración media, First Bloods.
- El valor va en `arc-gold-bright`; `.cyan` para datos informativos. `.success` y `.error` son de sistema: no los uses para ganador o perdedor.
- Lo que aportás: `.stat-strip` con un `.stat` por métrica (`.stat-label` y `.stat-value`).
