# WinCondition

Las tres formas de ganar una partida: First Blood, 100 CS y Primera torre.

- Siempre escritas; nunca solo un ícono o un color.
- `decided` marca la que definió la partida: dorado, brillo chico y el minuto en `.win-cond-time` ("First Blood · 06:42").
- Van juntas en `.win-conds`, siempre en el orden First Blood, 100 CS, Primera torre.
- Lo que aportás: un `<span class="win-cond">` por condición y la clase `decided` en la que ganó.
