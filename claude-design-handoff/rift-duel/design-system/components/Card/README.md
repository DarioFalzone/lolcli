# Card

Contenedor base del source: `card-header` con el título y `card-body` con el contenido.

- Agrupa información de una misma cosa: reglas, resumen de una partida, stats.
- El título va en `arc-gold-bright`; a la derecha, como mucho una pill o una acción.
- `card interactive` suma hover (sube 2px, brillo dorado chico) cuando toda la card es clickeable.
- Lo que aportás: `<article class="card">` con `<header class="card-header"><h3>…</h3></header>` y `<div class="card-body">`.
