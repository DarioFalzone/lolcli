# Banner

Mensaje en línea (`banner`) y aviso flotante (`toast`) del source.

- `banner info` para reglas y datos útiles ("Fearless: …"). `success`, `warning` y `error` para lo que devuelve el sistema.
- `toast` confirma una acción recién hecha ("Partida 2 guardada"): lleva un punto de color (`.dot`) y el texto.
- Un banner por zona; no los apiles.
- Lo que aportás: un `<div class="banner info">` (o `<span class="toast success">`) con el texto.
